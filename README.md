# spotify-tg-profile

Показывает в профиле Telegram, что ты сейчас слушаешь в Spotify:

- **аватарка** — обложка трека;
- **био** — «🎧 Исполнитель — Трек»;
- **эмодзи-статус** — подбирается под трек: по словам в названии, жанру или цвету обложки *(Telegram Premium)*;
- **цвет профиля** — под цвет обложки *(Telegram Premium)*.

Музыка на паузе или бот остановлен — профиль возвращается как был: твои аватарки, био, статус и цвет бот не трогает
и не теряет. Управляется командами в «Избранном» (`.status`, `.off`, `.ban`…).

> **Это юзербот:** он входит в твой аккаунт Telegram как обычное приложение и меняет профиль от твоего имени.
> Сессия и ключи хранятся только у тебя на компьютере. Telegram ограничивает частоту смены профиля —
> бот это учитывает (см. «Лимиты Telegram»), но используешь ты его на свой страх и риск.

## Что нужно

- Python 3.11+ (проверялось на 3.14 и только на Windows; автозапуск в фоне — только Windows);
- аккаунт Telegram; для эмодзи-статуса и цвета профиля — Premium;
- **Spotify Premium**: с февраля 2026 без него не работают приложения в Spotify Developer Dashboard.

Общего сервера нет — каждый запускает бота у себя со своими ключами.

## Установка

1. **Ключи Telegram.** На [my.telegram.org/apps](https://my.telegram.org/apps) создай приложение — получишь `api_id` и `api_hash`.
2. **Приложение Spotify.** В [Developer Dashboard](https://developer.spotify.com/dashboard) нажми Create app,
   в Redirect URIs добавь `http://127.0.0.1:8888/callback` (`localhost` Spotify не принимает), отметь Web API.
   Понадобятся Client ID и Client secret.
3. **Код и зависимости:**

   ```bash
   git clone https://github.com/eeffeecct/spotify-tg-profile.git
   cd spotify-tg-profile
   python -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   copy .env.example .env
   ```

   Необязательно: `pip install tgcrypto` ускоряет загрузку обложек.
4. **Впиши ключи в `.env`.** Остальные настройки там же, у всех есть значения по умолчанию.
5. **Первый запуск — в консоли:**

   ```bash
   .venv\Scripts\python main.py
   ```

   Откроется браузер для входа в Spotify, а Telegram спросит в консоли номер телефона и код.
   Дальше вход не нужен: сессия лежит в `my_account.session`, токен Spotify — в `.cache`. **Никому не отдавай эти файлы и `.env`.**

Остановка — `Ctrl+C`, профиль вернётся как был. Если бота долго не запускать, Telegram и Spotify закрывают вход:
токен Spotify бот обновит сам (откроет браузер), а для Telegram нужно удалить `.session` и войти заново.

## Как это работает

Бот раз в `POLL_INTERVAL` секунд спрашивает у Spotify текущий трек. Трек попадает в профиль, когда играет `MIN_LISTEN` секунд, —
пролистанные треки игнорируются. Пауза дольше `IDLE_TIMEOUT` секунд — профиль возвращается к обычному виду.

### Лимиты Telegram

Telegram ограничивает, как часто можно менять профиль, и самое дефицитное — аватарка: по опыту, примерно после 85 смен
за сутки он блокирует загрузку на часы. Поэтому:

- текст, эмодзи и цвет меняются на каждом треке (до `MAX_UPDATES` подряд, дальше раз в `UPDATE_REFILL` секунд);
- обложка ставится сразу, если прошлый трек ты слушал, а не пролистал; когда листаешь — только тому треку,
  который играет `PHOTO_MIN_LISTEN` секунд (до этого видна твоя настоящая аватарка, а не обложка от другого трека);
- не больше `PHOTO_DAILY_LIMIT` аватарок в сутки, счётчик виден в `.status`;
- если Telegram всё-таки что-то ограничил, бот не зависает: эту часть профиля не трогает до снятия лимита
  (пишет в `bot.log` и `.status`), остальное обновляет дальше.

## Работа в фоне и автозапуск (Windows)

Один раз войди в консоли (см. выше), потом:

```bash
.venv\Scripts\python autostart.py install   # в автозагрузку + запустить сейчас, без окна
.venv\Scripts\python autostart.py remove    # убрать из автозагрузки
.venv\Scripts\python autostart.py start     # просто запустить в фоне
```

Лог — `bot.log`. Второй экземпляр не запустится (на одну сессию нельзя два бота). Если бот упадёт — перезапустится сам.

## Команды в «Избранном» Telegram

Пиши себе в «Избранное» — бот ответит, отредактировав сообщение:

| Команда | Что делает |
|---|---|
| `.status` | что сейчас в Spotify и в профиле |
| `.off` / `.on` | пауза (профиль возвращается как был) / включить обратно |
| `.ban` | скрыть текущий трек |
| `.ban Имя артиста` | скрыть артиста |
| `.unban [Имя артиста]` | убрать из чёрного списка (без имени — текущий трек) |
| `.bans` | чёрный список |
| `.emoji 🔥` | эмодзи-статус для текущего трека |
| `.emoji Имя артиста 🔥` | эмодзи-статус для артиста |
| `.emoji ~слово 🌧` | если слово есть в названии трека |
| `.emoji * 🎶` | когда нет слов и жанра (вместо сердечка по цвету обложки) |
| `.unemoji [ключ]`, `.emojis` | убрать правило / все правила |
| `.stop` | вернуть профиль и выключить бота |
| `.help` | список команд |

Чёрный список лежит в `blacklist.txt` — его можно править и руками: по строке `spotify:track:…` или имя артиста.
Трек из чёрного списка бот считает «ничего не играет».

Эмодзи-статус подбирается сам, по порядку:
1. твои правила: трек → артист → `~слово` (любые премиум-эмодзи из наборов — выбери в панели прямо в команде);
2. слова в названии (англ. и рус.): love/любовь → ❤️, money/деньги → 💸, rain/дождь → 🌧, night/ночь → 🌙…;
3. жанр артиста из Spotify: rap → 🎤, rock → 🎸, r&b → 💜, phonk → 🏎… (у многих артистов жанров нет);
4. правило `*`, если задано;
5. сердечко цвета обложки: ❤️🧡💛💚🩵💙💜🩷🤍🖤.

Почему выбран такой эмодзи — видно в `.status` и в `bot.log`. Выключить автоподбор — `AUTO_EMOJI=0` в `.env`.
Правила лежат в `emoji_rules.txt` (`Drake = 🔥`, `~rain = 🌧`, `* = 🎶`), их можно править руками.
