# spotify_tg_bot

Пока играет музыка в Spotify — ставит обложку трека на аватарку Telegram, а «Исполнитель — Трек» в био.
С Telegram Premium ещё ставит 🎧 в эмодзи-статус (до конца трека) и красит профиль в цвет обложки.
Когда музыка на паузе дольше `IDLE_TIMEOUT` или скрипт остановлен — удаляет свою обложку и возвращает исходное био.
Твои настоящие аватарки не трогает, свой статус и цвет профиля вернутся как были.
Быстро листаешь треки — профиль не дёргается: трек должен играть `MIN_LISTEN` секунд, а менять профиль бот будет не больше `MAX_UPDATES` раз за `UPDATE_WINDOW` секунд.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env   # и заполнить
.venv\Scripts\python main.py
```

- **Spotify**: в [Dashboard](https://developer.spotify.com/dashboard) → приложение → Settings → Redirect URIs добавить
  `http://127.0.0.1:8888/callback` (`localhost` Spotify больше не принимает). При первом запуске откроется браузер для входа.
- **Telegram**: при первом запуске попросит номер телефона и код, потом сессия хранится в `my_account.session`.
  Если долго не запускать, Telegram убивает сессию — тогда удалить `.session` и войти заново.

Остановка — `Ctrl+C` (профиль вернётся как был).

- Нужен **Spotify Premium** у владельца приложения в Dashboard (правило Spotify с февраля 2026).
- `pip install tgcrypto` — необязательно, но ускоряет загрузку обложек.

## Работа в фоне и автозапуск (Windows)

Один раз войди в консоли (см. выше), потом:

```bash
.venv\Scripts\python autostart.py install   # в автозагрузку + запустить сейчас, без окна
.venv\Scripts\python autostart.py remove    # убрать из автозагрузки
.venv\Scripts\python autostart.py start     # просто запустить в фоне
```

Лог — `bot.log`. Второй экземпляр не запустится (на одну сессию нельзя два бота). Если бот упадёт — перезапустится сам.

## Команды в «Избранном» Telegram

Пиши себе в «Избранное» — бот ответит, отредактировав сообщение:

| Команда | Что делает |
|---|---|
| `.status` | что сейчас в Spotify и в профиле |
| `.off` / `.on` | пауза (профиль возвращается как был) / включить обратно |
| `.ban` | скрыть текущий трек |
| `.ban Имя артиста` | скрыть артиста |
| `.unban [Имя артиста]` | убрать из чёрного списка (без имени — текущий трек) |
| `.bans` | чёрный список |
| `.stop` | вернуть профиль и выключить бота |
| `.help` | список команд |

Чёрный список лежит в `blacklist.txt` — его можно править и руками: по строке `spotify:track:…` или имя артиста.
Трек из чёрного списка бот считает «ничего не играет».
